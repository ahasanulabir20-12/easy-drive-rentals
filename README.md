# Easy Drive Rentals

Create a professional, modern car rental website titled "Easy_Car".


Color Aesthetic: High-contrast Yellow (#FFD700), Deep Black (#18181B), and clean accents of Red. Use a white background for content sections to ensure a premium feel.
Core Structure & Features:
Hero Section: Bold heading "Your Premium Ride, Just a Click Away". Include a booking widget with: "From", "To", "Date", and a toggle switch for "Inside Dhaka" vs "Outside Dhaka".
Pricing Table Section: Create a clean, structured table titled "Estimated Fare Guide". Include columns for:
Vehicle Type (CNG, Axio, Allion, Noah, Hiace, Bus).
Service Area (Inside Dhaka Daily / Outside Dhaka Trip).
Estimated Base Fare (Use placeholders like 2,500 BDT, 5,000 BDT, etc.).
Note: Mention "Fares are variable based on gas/fuel prices and distance."
Fleet Showcase: Cards for each car model (CNG, Axio, Allion, Noah, Hiace, Bus) with a "Book Now" button that scrolls to the contact form.
Service Options: Add a selection for Daily Rental, Airport Transfer, and Event/Wedding Support.
Contact & CTA: >    - A dedicated "Contact Us" section with Phone, Email, and a "Request a Quote" form.
A Floating WhatsApp Button for instant communication.
A sticky header with a "Call Now" button in Yellow/Black theme.
Design Tone: Minimalist icons (using Lucide-react), bold typography, and smooth transitions. Ensure the pricing table is fully responsive on mobile devices.
